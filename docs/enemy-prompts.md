# Enemy character sheets (matches the Valeria anchor style)

Five sheets: three for enemies that have **no model yet** (19 of them), two optional ones that **redo the 12 older, gritty enemies** in the cartoony style so the whole roster matches. Attach the Valeria anchor to every prompt. Save the results in `assets-src/enemies/` with the names below (`aurelion`, `nexus`, `rift`, and optionally `redo-1`, `redo-2`) and I'll cut them with `tools/pack-arenas.ps1`.

Rules that matter for the game (already in the prompts): every enemy **faces LEFT**, because the player stands on the left; a three-quarter view looking left is ideal. Figures are in reading order (left to right, top row first), because the order is how I name them. Sizes inside the game come from the code, not the sheet, so draw bosses a bit larger than the small ones, but keep every figure fully inside its own cell.

Common block used in all five prompts (already included in each one below, nothing to paste separately).
