# Balance assessment 0.197.0

2026-11-04 · rules 80 · Implemented release candidate; Robert authorized push/deploy after validation. Only review P4 plus timer/lore included. · source: Working tree based on 9f16335; decision 602. Includes decisions 598/600, rules 80.

Static rule/card review and conditional arithmetic. No simulations or measured matchup dataset. Updates the rules 79 ten-plus-turn review for the implemented Heavy Hitter/Resonant Pulse changes. Other proposals remain unapplied; unchanged estimates are carried forward, not newly measured.

Measured matches used: 0. Target: Distinct A-band styles in both modes, typical competitive Arena games ten-plus turns per player; proposed working band 10-14, not a hard minimum or a measured result. Campaign XVII-XX difficult but beatable.

Grades are estimates of complete deck strength, not isolated passive value. A+/A/A− are competitive sub-bands; B indicates a meaningful reliability problem; S flags a suspected outlier. They are not win rates. Ascendancies unlock after Tier III. Developing = IV–X, deep = XI–XVI, endgame = XVII–XX. Fight opening = turns 1–3; extended = turns 6–10. These bands describe different things.

## Reasoning and next checks

### Paladin

Retention supports defense and Barrier attacks, but constant Barrier generation converges rather than growing forever. More turns help only if the deck increases its generation or converts it into a finish. Confidence: low; no measured matchup dataset.

Watch: Timeout/sustain risk; piercing and direct HP loss bypass the main defense.
