# Balance assessment 0.194.0

2026-11-04 · rules 78 · Released baseline, retrospective assessment revision 2; original assessment preserved · source: 92466e2

Theorycraft assessment of plausible developed decks at comparable upgrade quality. No balance simulations or real-match dataset used. Grades include the class pool and base trait; the marginal Ascendancy is discussed separately. A deterministic fixture establishes behavior, never a win-rate or a tier grade.

Measured matches used: 0. Target: Three or more distinct competitive A-band play styles per class in both modes; campaign XVII–XX extremely difficult but beatable. This is an acceptance target, not established parity.

Grades are estimates of complete deck strength, not isolated passive value. A+/A/A− are competitive sub-bands; B indicates a meaningful reliability problem; S flags a suspected outlier. They are not win rates. Ascendancies unlock after Tier III. Developing = IV–X, deep = XI–XVI, endgame = XVII–XX. Fight opening = turns 1–3; extended = turns 6–10. These bands describe different things.

## Corrections and limits

- Original Swarmwright A− estimate overlooked the optimized free recycle loop. Corrected ceiling is an exploit/outlier, not a valid balanced A− deck.
- Storm Sovereign commands/push-outs trigger it; standing passives never did. Earlier broad descriptions inflated the assumed sustain.
- Scent of Weakness failed against opponent heroes. Its PvE value did not transfer equally to Arena.
- Campaign/sub-band baseline estimates were first authored on this date, not measured or contemporaneous playtest results.
- Unchanged card-pool efficiency may dominate differences between Ascendancies. No measured win rates are available.
- Revision 2 corrects progression/opening/extended sub-grades for changed mechanics: the first retrospective baseline copied several projected sub-grades from the new pass. Original overall Arena grades remain intact. Golemancer/Bonelord/Deathwish reliability and unlimited Predator/Fracture/Harvest ceilings are now distinguished more accurately.
